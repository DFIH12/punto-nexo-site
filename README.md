# Punto Nexu — sitio web v1

Primera versión local y estática de la página comercial de Punto Nexu.

## Ejecutar

```bash
python3 -m http.server 8080 --directory /root/punto-nexo-site
```

Abrir `http://127.0.0.1:8080`.

## Alcance

- Hero enfocado en solicitudes de cotización.
- Servicios, proceso y planes.
- Formulario que prepara un mensaje de WhatsApp sin almacenar datos.
- Navegación y diseño adaptable a móvil.
